\section{STATE}

We benchmarked the State Embedding (``SE'') stage of STATE\cite{adduri2025state}, a self-supervised cell-embedding transformer trained with a tabular energy loss over masked gene-expression ``sentences''. Each cell is tokenized into a sequence of (gene, count) pairs, gene tokens are mapped to fixed protein-language-model embeddings, and the sequence is processed by a transformer encoder; a reconstruction decoder predicts per-gene expression values across the masked positions.

Following the published recipe, gene tokens are replaced with pretrained protein embeddings from TranscriptFormer\cite{pearce2025transcriptformer}, a cross-species single-cell foundation model that encodes each gene using ESM-2\cite{lin2023esm2} protein language model embeddings. We use the 2{,}560-dimensional gene embeddings released by TranscriptFormer for both \emph{Mus musculus} and \emph{Homo sapiens}, merged into a single multi-species table.

To make STATE comparable to the Geneformer baseline used elsewhere in this study, we override the published SE defaults to a smaller architecture (Table~\ref{tab:state_params}). The full set of hyperparameters used for from-scratch training is reported in Table~\ref{tab:state_params}.

Unlike Geneformer and SCVI, STATE training duration is governed by a fixed \emph{step} budget chosen so that the total amount of optimization remains roughly constant across the sweep, with step-based early stopping acting as an upper bound. After training, the best checkpoint is selected by minimum validation loss, and cell embeddings are extracted from this checkpoint for downstream mutual-information estimation.

Figure~\ref{fig:state_training_loss} shows representative training and validation loss curves for SE trained on PBMC at the largest dataset size (46{,}415 cells) and full quality. Both losses decrease monotonically and the validation curve closely tracks training, indicating stable convergence without overfitting.

\section{Fine-Tuning the Pretrained SE-100M Model}

In addition to training STATE from scratch, we evaluated fine-tuning the publicly released Arc Institute SE-100M embedding model\cite{adduri2025state} on the PBMC noise-scaling grid. SE-100M was pretrained on a large multi-dataset corpus using the full STATE self-supervised objective with dataset-level batch correction. To fine-tune SE-100M, we first downloaded the pretrained model checkpoint and stripped all optimizer and scheduler state, resetting the epoch and step counters to zero while retaining the model weights. This ensures that fine-tuning begins from the pretrained representation with a freshly initialized optimizer and learning-rate schedule. For each (size, quality) cell in the grid, gene token mappings were re-generated using SE-100M's own protein embedding vocabulary---also based on ESM-2\cite{lin2023esm2}---so that the tokenization is consistent with the pretrained weights. The stripped checkpoint was then placed as the training start point for each cell. Each cell was fine-tuned independently for a fixed 3-epoch budget with early stopping disabled, so all cells received the same number of epochs. The batch-correction head was kept enabled during fine-tuning (matching the pretrained architecture exactly) to avoid weight-shape mismatches at checkpoint load; the head receives a placeholder dataset label signal on PBMC that does not affect the encoder gradients. After fine-tuning, cell embeddings were extracted from the end-of-training checkpoint and mutual information was estimated against \texttt{celltype.l3} and \texttt{protein\_counts}. The fine-tuning hyperparameters are summarized in Table~\ref{tab:finetune_params}.
